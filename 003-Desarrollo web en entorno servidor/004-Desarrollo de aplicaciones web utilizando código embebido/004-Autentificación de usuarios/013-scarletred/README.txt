- Listado y formulario se muestran por separado.
- Alta, edición y borrado dinámicos.
- PK detectada automáticamente.

- Login coherente con el escritorio.
- Consultas de login y CRUD parametrizadas.

La base empresa.db incluida se ha reconstruido únicamente con el esquema documentado
